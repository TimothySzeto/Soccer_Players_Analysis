# Soccer Finishing Analysis

## Project Goal

Analyze which players outperform or underperform their expected goals (xG).

## Dataset

- Source: https://www.kaggle.com/datasets/hubertsidorowicz/football-players-stats-2024-2025?resource=download
- Competition: Top 5 European Leagues

## Methodology

1. Filter players with >1000 minutes played
2. Calculate Goals - xG
3. Visualize Goals vs xG
4. Identify top overperformers and underperformers

## Results

Patrik Schick, Bryan Mbeumo, Chris Wood, Matheus Cunha, and Ayoze Pérez significantly outperformed their xG.

Hugo Ekitike, Abde Ezzalzouli, Breel Embolo, Maghnes Akliouche, and Tammy Abraham significantly underperformed their xG.
